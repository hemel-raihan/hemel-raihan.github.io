# Md Hemel Raihan — Portfolio

Personal portfolio for [hemel-raihan.github.io](https://hemel-raihan.github.io/), built as a lightweight static site for GitHub Pages.

## Structure

- `index.html` — semantic content, SEO metadata and portfolio sections
- `style.css` — responsive visual system and project presentation
- `script.js` — navigation, reveal effects and project filtering
- `assets/resume/` — public résumé download
- `assets/projects/` — approved and redacted project screenshots

## Project visual workflow

Internal product screenshots must be reviewed before publishing. Remove or blur personal data, credentials, financial information, customer details, internal URLs and other confidential values. Screenshots should ideally be exported at 1600×1000 or larger in PNG/WebP format.

Each project will receive its own folder and curated gallery when approved visuals are available.

## Local preview

The site has no build step. Open `index.html` directly or serve the folder with any static HTTP server.

## Deployment

Push the repository's default branch to GitHub. GitHub Pages serves the site from the repository root.
